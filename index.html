    What it does

    The parts of a photo that never show up on screen

    A JPEG is a stack of segments. The picture is only some of them. The rest is paperwork: who took it, where, on what, with which lens, edited in which app, and sometimes the entire AI prompt used to generate it.

    MetaShield walks that structure byte by byte. It reads every segment, shows you what each one holds, then rebuilds the file without the ones you don't want — leaving the compressed image data byte-for-byte identical. No canvas, no re-encode, no quality loss.

    • Inspect first. A readable report of every tag, chunk and segment, with a privacy score.
    • Then clean. Remove GPS, camera identity, timestamps, IPTC, XMP, comments and AI prompts.
    • Or write. Add your own author, copyright and description inside the file.

    Features

    Small tool, serious engine

    Built for people who actually care what happens to their files.

    01

    True binary stripping

    JPEG segments, PNG chunks and WebP RIFF blocks are cut at the byte level. Your image data is copied, never decoded or re-compressed.

    02

    Readable inspection

    GPS coordinates, camera make and model, lens, ISO, shutter, edit software, IPTC captions and AI prompts — laid out in plain language.

    03

    Write your own tags

    Injects Author, Copyright and Description into EXIF, PNG iTXt or WebP XMP — properly formed, three bytes short of bloated.

    04

    Bulk without limits

    Hundreds of files at once, folders included. Everything lands in one ZIP — written by the app itself, so no dependency downloads.

    05

    Colour-safe modes

    Smart mode keeps ICC profiles and the Adobe transform marker, so wide-gamut and CMYK photos don't shift colour after cleaning.

    06

    Offline by design

    Installable PWA with a local service worker. Server, account and tracker count: zero. Works in airplane mode after the first visit.

    One thing worth knowing: some phone photos are stored sideways with an EXIF flag telling viewers to rotate them. Stripping that flag makes them look rotated. MetaShield reads it first and can keep it — that switch is on by default.

    FAQ

    Fair questions

    Does cleaning change how my photo looks?

    No. The compressed image data is copied byte for byte, and the app re-parses its own output to confirm the pixel stream hash matches the original. In smart mode the colour profile is kept too, so colour reproduction stays the same.

    Are my files uploaded anywhere?

    Never. The app is a static page with no backend. You can disconnect from the network and it still works. That is also why it installs as an app: the whole thing is cached on your device.

    Which files are supported?

    JPEG (baseline and progressive), PNG (including APNG animation, which is preserved) and WebP (lossy, lossless and animated). Other formats are rejected rather than silently mangled.

    Will it remove watermarks?

    No. Visible watermarks are part of the picture. MetaShield only removes metadata — hidden text, tags and appended blocks. It is not a watermark remover.

    What does strip appended data do?

    Some tools attach extra bytes after the end of the image. Viewers ignore them, but they can hold hidden payloads. Removing them is safe; leaving them keeps the file bit-identical apart from the metadata you removed.
